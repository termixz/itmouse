События Мыши

События мыши позволяют отслеживать движение курсора и взаимодействие пользователя с мышью.

Основные события мыши:

  • click - возникает при клике мышью (нажатие и отпускание)
  • dblclick - возникает при двойном клике
  • mousedown - возникает при нажатии кнопки мыши
  • mouseup - возникает при отпускании кнопки мыши
  • mousemove - возникает при движении мыши
  • mouseover - возникает при наведении курсора на элемент
  • mouseout - возникает при уходе курсора с элемента
  • mouseenter - возникает при входе курсора в элемент (не всплывает)
  • mouseleave - возникает при выходе курсора из элемента (не всплывает)
  • contextmenu - возникает при вызове контекстного меню (правый клик)
  • wheel - возникает при использовании колеса мыши

Пример использования событий мыши

Вот простой пример обработки события клика мыши:

Нажмите на меня
Статус: ожидание клика 
// 1. Получаем ссылку на элемент, с которым будем работать
const button = document.getElementById('clickDemo');
const output = document.getElementById('clickOutput');

// 2. Добавляем обработчик события click
button.addEventListener('click', function(event) {
    // 3. Эта функция будет вызвана при клике
    
    // 4. Получаем информацию о событии
    const x = event.clientX; // X-координата клика относительно окна
    const y = event.clientY; // Y-координата клика относительно окна
    
    // 5. Получаем координаты относительно самого элемента
    const offsetX = event.offsetX;
    const offsetY = event.offsetY;
    
    // 6. Выводим информацию о событии
    output.innerHTML = `Клик на координатах: X=${x}, Y=${y}

                        Внутри элемента: X=${offsetX}, Y=${offsetY}`;
    
    // 7. Изменяем стиль элемента для визуальной обратной связи
    // Переключаем цвет при каждом клике
    if (button.style.backgroundColor === 'rgb(231, 76, 60)') {
        button.style.backgroundColor = '#3498db';
    } else {
        button.style.backgroundColor = '#e74c3c';
    }
});

Объяснение кода:

  1. Получение элементов - с помощью document.getElementById() находим элементы, с которыми будем работать.
  2. Добавление обработчика - используем метод addEventListener, который принимает:
    • Название события ('click')
    • Функцию-обработчик, которая будет вызвана при наступлении события
  3. Обработчик события - функция, которая автоматически получает объект события event с информацией о событии.
  4. Объект события - содержит свойства:
    • clientX/clientY - координаты относительно окна браузера
    • offsetX/offsetY - координаты относительно самого элемента
    • и многие другие свойства (target, type, button...)
  5. Обработка события - в данном случае мы:
    • Выводим информацию о координатах клика
    • Переключаем цвет элемента

Свойства объекта события мыши:

Свойство Описание
clientX, clientY Координаты относительно окна браузера
pageX, pageY Координаты относительно документа
screenX, screenY Координаты относительно экрана
offsetX, offsetY Координаты относительно элемента, на котором произошло событие
button Какая кнопка мыши была нажата (0 - левая, 1 - средняя, 2 - правая)
buttons Битовая маска нажатых кнопок мыши во время события

Следующий шаг: Теперь, когда вы знаете о событиях мыши, давайте рассмотрим события клавиатуры.

Дополнительные примеры работы с событиями мыши

1. Отслеживание основных событий мыши

Наведите курсор
const box = document.getElementById('eventBox');
const output = document.getElementById('eventOutput');

// Клик мышью
box.addEventListener('click', function() {
    output.innerHTML = 'Событие: click';
    if (box.style.backgroundColor === 'rgb(231, 76, 60)') {
        box.style.backgroundColor = '#3498db';
    } else {
        box.style.backgroundColor = '#e74c3c';
    }
});

// Наведение мыши
box.addEventListener('mouseover', function() {
    output.innerHTML = 'Событие: mouseover';
    box.textContent = 'Курсор над элементом';
});

// Уход мыши с элемента
box.addEventListener('mouseout', function() {
    output.innerHTML = 'Событие: mouseout';
    box.textContent = 'Наведите курсор';
});

// Нажатие кнопки мыши
box.addEventListener('mousedown', function() {
    output.innerHTML = 'Событие: mousedown';
    box.textContent = 'Кнопка мыши нажата';
});

// Отпускание кнопки мыши
box.addEventListener('mouseup', function() {
    output.innerHTML = 'Событие: mouseup';
    box.textContent = 'Кнопка мыши отпущена';
});

2. Отслеживание координат мыши

Перемещайте курсор над областью:

const tracker = document.getElementById('coordinateTracker');
const cursor = document.getElementById('trackerCursor');
const coordinates = document.getElementById('coordinatesOutput');

tracker.addEventListener('mousemove', function(event) {
    // Получаем координаты мыши относительно окна браузера
    const clientX = event.clientX;
    const clientY = event.clientY;
    
    // Получаем координаты мыши относительно элемента tracker
    const offsetX = event.offsetX;
    const offsetY = event.offsetY;
    
    // Обновляем позицию красного круга
    cursor.style.left = offsetX + 'px';
    cursor.style.top = offsetY + 'px';
    
    // Выводим информацию о координатах
    coordinates.innerHTML = `
        clientX: ${clientX}, clientY: ${clientY}

        offsetX: ${offsetX}, offsetY: ${offsetY}
    `;
});

tracker.addEventListener('mouseleave', function() {
    cursor.style.display = 'none';
});

tracker.addEventListener('mouseenter', function() {
    cursor.style.display = 'block';
});

4. Перетаскивание элемента (простой drag and drop)

Перетащи меня
Координаты: x=50, y=50
const container = document.getElementById('simpleDragContainer');
const draggable = document.getElementById('simpleDraggable');
const status = document.getElementById('simpleDragStatus');

let isDragging = false;
let offsetX, offsetY;

// Начало перетаскивания
draggable.addEventListener('mousedown', function(e) {
    isDragging = true;
    
    // Вычисляем смещение от позиции клика до угла элемента
    offsetX = e.clientX - draggable.getBoundingClientRect().left;
    offsetY = e.clientY - draggable.getBoundingClientRect().top;
    
    draggable.style.opacity = '0.8';
});

// Процесс перетаскивания
document.addEventListener('mousemove', function(e) {
    if (!isDragging) return;
    
    // Вычисляем новые координаты с учетом смещения
    const containerRect = container.getBoundingClientRect();
    let x = e.clientX - containerRect.left - offsetX;
    let y = e.clientY - containerRect.top - offsetY;
    
    // Ограничиваем перемещение границами контейнера
    const maxX = containerRect.width - draggable.offsetWidth;
    const maxY = containerRect.height - draggable.offsetHeight;
    
    x = Math.max(0, Math.min(x, maxX));
    y = Math.max(0, Math.min(y, maxY));
    
    draggable.style.left = x + 'px';
    draggable.style.top = y + 'px';
    
    // Обновляем информацию о координатах
    status.textContent = `Координаты: x=${Math.round(x)}, y=${Math.round(y)}`;
});

// Завершение перетаскивания
document.addEventListener('mouseup', function() {
    if (isDragging) {
        isDragging = false;
        draggable.style.opacity = '1';
    }
});

5. Ховер-эффекты с изменением фона

const grid = document.getElementById('hoverGrid');
const resetBtn = document.getElementById('hoverResetBtn');
const hoverColor = document.getElementById('hoverColorPicker');

// Создаем сетку
for (let i = 0; i < 100; i++) {
    const cell = document.createElement('div');
    cell.className = 'hover-cell';
    cell.style.backgroundColor = '#f5f5f5';
    cell.style.transition = 'background-color 0.3s';
    grid.appendChild(cell);
}

// Делегируем события на сетку
grid.addEventListener('mouseover', function(e) {
    if (e.target.classList.contains('hover-cell')) {
        e.target.style.backgroundColor = hoverColor.value;
    }
});

// Добавляем функцию сброса
resetBtn.addEventListener('click', function() {
    document.querySelectorAll('.hover-cell').forEach(cell => {
        cell.style.backgroundColor = '#f5f5f5';
    });
});
