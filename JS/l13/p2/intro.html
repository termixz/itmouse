Введение в События JavaScript

События в JavaScript представляют собой действия или происшествия, которые происходят в браузере и на которые JavaScript может реагировать. События позволяют создавать интерактивные веб-страницы, реагирующие на действия пользователя.

События могут быть вызваны различными способами:

  • Действиями пользователя (щелчок мыши, нажатие клавиши, прокрутка)
  • Изменениями в DOM (загрузка страницы, изменение формы)
  • Программно (через JavaScript)

Основные Типы Событий

Категория События Описание
События мыши click, dblclick, mousedown, mouseup, mousemove, mouseover, mouseout Реагируют на действия мыши пользователя
События клавиатуры keydown, keyup, keypress Реагируют на нажатия клавиш
События формы submit, change, focus, blur Реагируют на взаимодействие с формами
События документа DOMContentLoaded, load, resize, scroll Реагируют на изменения в документе/окне

Важно: События являются основой интерактивности веб-страницы. Умение эффективно работать с событиями - ключевой навык веб-разработчика.

Пример простого использования события:

// Код примера
document.getElementById('simpleButton').addEventListener('click', function() {
    document.getElementById('simpleOutput').textContent = 'Кнопка была нажата!';
});
