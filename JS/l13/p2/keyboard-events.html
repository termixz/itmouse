События Клавиатуры

События клавиатуры возникают при взаимодействии пользователя с клавиатурой. Они позволяют обрабатывать нажатия клавиш и создавать различные интерактивные элементы управления.

Основные события клавиатуры:

  • keydown - возникает при нажатии клавиши
  • keyup - возникает при отпускании клавиши
  • keypress - возникает при нажатии клавиши, которая производит символ (устаревшее, рекомендуется использовать keydown)

Важно: Событие keypress считается устаревшим. В современном коде рекомендуется использовать keydown и keyup.

Свойства объекта события клавиатуры:

Свойство Описание
key Значение нажатой клавиши ("a", "Enter", "ArrowUp", и т.д.)
code Физический код клавиши ("KeyA", "Enter", "ArrowUp", и т.д.)
keyCode Числовой код клавиши (устаревшее)
altKey, ctrlKey, shiftKey, metaKey Был ли нажат Alt, Ctrl, Shift или Meta (Windows/Command) во время события
repeat Булево значение, указывающее на повторное срабатывание события при удержании клавиши

Пример отслеживания нажатия клавиш:

Нажмите любую клавишу (фокус должен быть на странице):

клик в эту область для активации
// Код для отслеживания нажатий клавиш
document.addEventListener('keydown', function(event) {
    // Получаем элемент для вывода информации
    const output = document.getElementById('keyboardOutput');
    
    // Обновляем содержимое с информацией о нажатой клавише
    output.innerHTML = 
        'Клавиша: ' + event.key + '
' +
        'Код: ' + event.code + '
' +
        'Alt: ' + event.altKey + '
' +
        'Ctrl: ' + event.ctrlKey + '
' +
        'Shift: ' + event.shiftKey;
    
    // Можно добавить разные действия для конкретных клавиш
    if (event.code === 'Space') {
        output.style.backgroundColor = '#ffeb3b';
        setTimeout(() => output.style.backgroundColor = '', 300);
    }
    
    if (event.code === 'KeyR' && event.ctrlKey) {
        // Предотвращаем перезагрузку страницы по Ctrl+R
        event.preventDefault();
        output.innerHTML += '
Предотвращено обновление страницы!';
    }
});

Различие между key и code

event.key - возвращает символ, соответствующий нажатой клавише, с учетом раскладки клавиатуры и регистра.
event.code - возвращает физическое положение клавиши на клавиатуре, независимо от раскладки.

Действие key code
Нажата латинская буква "a" "a" "KeyA"
Нажата латинская буква "A" (с Shift) "A" "KeyA"
Нажата кириллическая буква "ф" (на месте "a") "ф" "KeyA"
Нажата стрелка вверх "ArrowUp" "ArrowUp"

Пример: Простой игровой контроллер

Используйте клавиши WASD для перемещения объекта
// Код для управления элементом с помощью клавиш WASD
const player = document.getElementById('player');
let playerX = 135;
let playerY = 135;
const step = 10;

document.addEventListener('keydown', function(event) {
    // Перемещаем игрока в зависимости от нажатой клавиши
    switch(event.key.toLowerCase()) {
        case 'w':
            playerY = Math.max(0, playerY - step);
            break;
        case 's':
            playerY = Math.min(270, playerY + step);
            break;
        case 'a':
            playerX = Math.max(0, playerX - step);
            break;
        case 'd':
            playerX = Math.min(270, playerX + step);
            break;
    }
    
    // Обновляем позицию игрока
    player.style.top = playerY + 'px';
    player.style.left = playerX + 'px';
});

Дополнительные примеры использования событий клавиатуры

1. Простое отслеживание нажатий клавиш

Этот пример демонстрирует, как отслеживать нажатия отдельных клавиш и отображать их на экране. Нажмите любую клавишу на клавиатуре для проверки.

Нажатые клавиши будут отображаться здесь
const keysPressed = document.getElementById('keysPressed');
const pressedKeys = new Set();

// Обработчик нажатия клавиши
document.addEventListener('keydown', function(event) {
    pressedKeys.add(event.key);
    updateDisplay();
});

// Обработчик отпускания клавиши
document.addEventListener('keyup', function(event) {
    pressedKeys.delete(event.key);
    updateDisplay();
});

function updateDisplay() {
    if (pressedKeys.size === 0) {
        keysPressed.innerHTML = 'Нажатые клавиши будут отображаться здесь';
    } else {
        keysPressed.innerHTML = 'Сейчас нажаты: ' + 
            Array.from(pressedKeys).join(' + ');
    }
}

2. Интерактивная игра с клавиатурным управлением

Этот пример демонстрирует простую игру "Поймай квадрат", в которой нужно поймать красный квадрат, управляя синим кругом с помощью клавиш WASD.

Счет: 0
Используйте клавиши WASD для движения
Нажмите любую клавишу WASD для начала игры
// Инициализация игровых элементов
const game_player = document.getElementById('gamePlayer');
const game_target = document.getElementById('gameTarget');
const game_scoreDisplay = document.getElementById('gameScore');
const game_status = document.getElementById('gameStatus');
const game_area = game_player.parentElement;

// Игровые переменные
let game_playerX = 50;
let game_playerY = 50;
let game_targetX = parseInt(game_target.style.right || '70');
let game_targetY = parseInt(game_target.style.top || '100');
let game_score = 0;
let game_started = false;
let game_playerSpeed = 5;

// Функция для обновления позиции игрока
function game_updatePlayerPosition() {
    // Ограничиваем движение границами игрового поля
    const maxX = game_area.clientWidth - game_player.clientWidth;
    const maxY = game_area.clientHeight - game_player.clientHeight;
    
    game_playerX = Math.max(0, Math.min(game_playerX, maxX));
    game_playerY = Math.max(0, Math.min(game_playerY, maxY));
    
    game_player.style.left = game_playerX + 'px';
    game_player.style.top = game_playerY + 'px';
    
    // Проверяем столкновение с целью
    game_checkCollision();
}

// Функция для перемещения цели в случайное место
function game_moveTarget() {
    const maxX = game_area.clientWidth - game_target.clientWidth;
    const maxY = game_area.clientHeight - game_target.clientHeight;
    
    game_targetX = Math.floor(Math.random() * maxX);
    game_targetY = Math.floor(Math.random() * maxY);
    
    game_target.style.left = game_targetX + 'px';
    game_target.style.top = game_targetY + 'px';
}

// Функция для проверки столкновений
function game_checkCollision() {
    // Получаем границы игрока и цели
    const playerRect = game_player.getBoundingClientRect();
    const targetRect = game_target.getBoundingClientRect();
    
    // Проверяем пересечение
    if (
        playerRect.left < targetRect.right &&
        playerRect.right > targetRect.left &&
        playerRect.top < targetRect.bottom &&
        playerRect.bottom > targetRect.top
    ) {
        // Столкновение произошло!
        game_score++;
        game_scoreDisplay.textContent = 'Счет: ' + game_score;
        
        // Меняем позицию цели
        game_moveTarget();
        
        // Показываем эффект столкновения
        game_status.textContent = 'Поймал! +1 очко';
        game_status.style.color = '#4caf50';
        
        // Увеличиваем скорость игрока каждые 5 очков
        if (game_score % 5 === 0) {
            game_playerSpeed += 1;
            game_status.textContent = 'Скорость увеличена! Текущий счет: ' + game_score;
        }
        
        setTimeout(() => {
            game_status.textContent = 'Используйте WASD для движения';
            game_status.style.color = '';
        }, 1000);
    }
}

// Обработчик клавиатурных событий
document.addEventListener('keydown', function(event) {
    if (!game_started) {
        game_started = true;
        game_status.textContent = 'Игра началась! Используйте WASD для движения';
        // Устанавливаем начальную позицию цели
        game_moveTarget();
        setTimeout(() => {
            game_status.textContent = 'Поймайте красный квадрат';
        }, 1500);
    }
    
    // Определяем, какая клавиша нажата, и перемещаем игрока
    switch(event.key.toLowerCase()) {
        case 'w':
            game_playerY -= game_playerSpeed;
            game_player.style.transform = 'translateY(-3px)';
            break;
        case 's':
            game_playerY += game_playerSpeed;
            game_player.style.transform = 'translateY(3px)';
            break;
        case 'a':
            game_playerX -= game_playerSpeed;
            game_player.style.transform = 'translateX(-3px)';
            break;
        case 'd':
            game_playerX += game_playerSpeed;
            game_player.style.transform = 'translateX(3px)';
            break;
    }
    
    game_updatePlayerPosition();
});

// Сбрасываем трансформацию при отпускании клавиши
document.addEventListener('keyup', function(event) {
    if (['w', 'a', 's', 'd'].includes(event.key.toLowerCase())) {
        game_player.style.transform = 'translate(0, 0)';
    }
});

// Инициализация начальных позиций
game_player.style.left = game_playerX + 'px';
game_player.style.top = game_playerY + 'px';
game_target.style.left = 'auto';
game_target.style.right = '70px';
game_target.style.top = '100px';

3. Управление объектом с помощью стрелок

Этот пример демонстрирует управление элементом с помощью клавиш стрелок, а также обработку одновременного нажатия нескольких клавиш и разную скорость движения в зависимости от нажатия Shift.

Используйте стрелки для перемещения объекта.
Зажмите Shift для ускорения.
const arrowBox = document.getElementById('arrowBox');
const arrowStatus = document.getElementById('arrowStatus');
const arrowKeysPressed = new Set();

let boxX = 130;
let boxY = 130;
let isMoving = false;

// Функция для обновления положения
function updatePosition() {
    const speed = arrowKeysPressed.has('Shift') ? 5 : 2; // Больше скорость с Shift
    
    if (arrowKeysPressed.has('ArrowUp')) {
        boxY = Math.max(0, boxY - speed);
    }
    if (arrowKeysPressed.has('ArrowDown')) {
        boxY = Math.min(260, boxY + speed);
    }
    if (arrowKeysPressed.has('ArrowLeft')) {
        boxX = Math.max(0, boxX - speed);
    }
    if (arrowKeysPressed.has('ArrowRight')) {
        boxX = Math.min(260, boxX + speed);
    }
    
    arrowBox.style.top = boxY + 'px';
    arrowBox.style.left = boxX + 'px';
    
    // Визуальная индикация скорости
    if (arrowKeysPressed.has('Shift')) {
        arrowBox.style.boxShadow = '0 0 10px 2px rgba(255, 87, 34, 0.7)';
    } else {
        arrowBox.style.boxShadow = '0 0 5px rgba(0, 0, 0, 0.3)';
    }
    
    // Продолжаем движение, пока нажаты клавиши
    if (arrowKeysPressed.size > 0 && (arrowKeysPressed.has('ArrowUp') || arrowKeysPressed.has('ArrowDown') || 
        arrowKeysPressed.has('ArrowLeft') || arrowKeysPressed.has('ArrowRight'))) {
        isMoving = true;
        requestAnimationFrame(updatePosition);
    } else {
        isMoving = false;
    }
}

// Обработчик нажатия клавиши
document.addEventListener('keydown', function(event) {
    if (['ArrowUp', 'ArrowDown', 'ArrowLeft', 'ArrowRight', 'Shift'].includes(event.key)) {
        // Предотвращаем прокрутку страницы при нажатии на стрелки
        event.preventDefault();
        
        // Добавляем клавишу в множество нажатых клавиш
        arrowKeysPressed.add(event.key);
        
        // Если движение еще не запущено, запускаем
        if (!isMoving) {
            updatePosition();
        }
    }
});

// Обработчик отпускания клавиши
document.addEventListener('keyup', function(event) {
    // Удаляем клавишу из множества нажатых клавиш
    arrowKeysPressed.delete(event.key);
});

Объяснение этого примера:

  1. Отслеживание нескольких клавиш - используется объект Set для хранения всех нажатых в данный момент клавиш, что позволяет обрабатывать несколько одновременных нажатий.
  2. Плавное движение - используется requestAnimationFrame для создания плавного движения, вместо резких перемещений при каждом нажатии.
  3. Клавиши стрелок - демонстрируется работа с клавишами навигации: ArrowUp, ArrowDown, ArrowLeft, ArrowRight.
  4. Модификаторы - использование клавиши Shift как модификатора, изменяющего параметры движения (скорость).
  5. Предотвращение стандартного поведения - использование event.preventDefault() для отключения прокрутки страницы при нажатии стрелок.
  6. Визуальная обратная связь - добавление эффекта тени при ускорении движения для лучшего пользовательского опыта.

Этот пример хорошо демонстрирует более сложные сценарии обработки клавиатурных событий, когда требуется отслеживать одновременное нажатие нескольких клавиш и создавать плавную анимацию.
