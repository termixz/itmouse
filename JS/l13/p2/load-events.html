События загрузки документа

События загрузки позволяют отслеживать различные этапы загрузки веб-страницы и её ресурсов. Понимание этих событий критически важно для правильной инициализации скриптов и оптимизации производительности.

Основные события загрузки

Событие Описание Использование
DOMContentLoaded DOM-дерево построено Инициализация UI, навешивание обработчиков
load Загружены все ресурсы Работа с изображениями, стилями
beforeunload Перед закрытием страницы Предупреждения о несохраненных данных
unload Страница закрывается Финальная отправка данных

Предупреждение перед закрытием

Нажмите кнопку, чтобы активировать предупреждение при попытке закрыть страницу:

Примеры кода

// 1. DOMContentLoaded - DOM построен
document.addEventListener('DOMContentLoaded', function() {
    console.log('DOM готов к использованию');
    // Теперь можно безопасно работать с DOM
    const element = document.getElementById('myElement');
});

// 2. load - страница и ресурсы загружены
window.addEventListener('load', function() {
    console.log('Страница полностью загружена');
    // Доступны все ресурсы: картинки, стили, скрипты
});

// 3. beforeunload - перед закрытием страницы
window.addEventListener('beforeunload', function(e) {
    // Показать предупреждение перед закрытием
    e.preventDefault();
    e.returnValue = '';
});

// 4. unload - закрытие страницы
window.addEventListener('unload', function() {
    // Последние действия перед закрытием
    navigator.sendBeacon('/api/log', 'Пользователь ушел');
});

Важные моменты при работе с событиями загрузки:

  • DOMContentLoaded срабатывает раньше, чем load
  • Используйте DOMContentLoaded для работы с DOM
  • Используйте load, когда нужны все ресурсы
  • beforeunload позволяет предотвратить случайное закрытие
  • В unload можно отправить только асинхронные запросы
  • Порядок загрузки: DOMContentLoaded → load → beforeunload → unload

Практический пример инициализации скриптов

При разработке веб-приложений важно правильно инициализировать скрипты. Рассмотрим пример, демонстрирующий разницу между правильным и неправильным подходом:

❌ Неправильный подход

// Может вызвать ошибку, если DOM ещё не загружен
const button = document.getElementById('demoButton');
const input = document.getElementById('demoInput');

button.addEventListener('click', () => {
    input.value = 'Нажата кнопка';
});

✅ Правильный подход

document.addEventListener('DOMContentLoaded', () => {
    const button = document.getElementById('demoButton');
    const input = document.getElementById('demoInput');
    
    button.addEventListener('click', () => {
        input.value = 'Нажата кнопка';
    });
});

Преимущества использования DOMContentLoaded:

  • Гарантирует доступность всех DOM-элементов
  • Предотвращает ошибки "Cannot read property of null"
  • Позволяет структурировать код инициализации
  • Работает независимо от расположения скрипта в документе

Важно: Если вам нужно работать с ресурсами (изображения, стили), используйте событие load вместо DOMContentLoaded:

window.addEventListener('load', () => {
    // Теперь доступны все ресурсы
    const images = document.getElementsByTagName('img');
    console.log('Загружено изображений:', images.length);
});
