JavaScript События

Введение в События JavaScript

События в JavaScript представляют собой действия или происшествия, которые происходят в браузере и на которые JavaScript может реагировать. События позволяют создавать интерактивные веб-страницы, реагирующие на действия пользователя.

События могут быть вызваны различными способами:

  • Действиями пользователя (щелчок мыши, нажатие клавиши, прокрутка)
  • Изменениями в DOM (загрузка страницы, изменение формы)
  • Программно (через JavaScript)

Основные Типы Событий

Категория События Описание
События мыши click, dblclick, mousedown, mouseup, mousemove, mouseover, mouseout Реагируют на действия мыши пользователя
События клавиатуры keydown, keyup, keypress Реагируют на нажатия клавиш
События формы submit, change, focus, blur Реагируют на взаимодействие с формами
События документа DOMContentLoaded, load, resize, scroll Реагируют на изменения в документе/окне

Методы Обработки Событий

Существует три основных способа добавления обработчиков событий:

1. HTML-атрибуты (не рекомендуется)

<button onclick="alert('Кнопка нажата!')">Нажми меня</button>

2. Свойства объекта DOM

let button = document.querySelector('button');
button.onclick = function() {
    alert('Кнопка нажата!');
};

Демонстрация:

Важно: Используя свойства объекта DOM, мы можем назначить только один обработчик для каждого типа события на элементе.

3. Метод addEventListener (рекомендуется)

let button = document.querySelector('button');
button.addEventListener('click', function() {
    alert('Кнопка нажата!');
});

// Можно добавить несколько обработчиков
button.addEventListener('click', function() {
    console.log('Еще один обработчик для того же события');
});

Демонстрация:

Объект Event

При возникновении события создается объект Event, который содержит детали о произошедшем событии и автоматически передается в функцию-обработчик. 

button.addEventListener('click', function(event) {
    console.log(event.type);      // "click"
    console.log(event.target);    // элемент, на котором произошло событие
    console.log(event.clientX);   // X-координата клика (для событий мыши)
    console.log(event.clientY);   // Y-координата клика (для событий мыши)
});

Демонстрация:

Распространение Событий (Event Propagation)

В JavaScript события распространяются через DOM-дерево в три фазы:

  1. Фаза захвата (Capturing phase) - событие спускается от корневого элемента к цели
  2. Фаза цели (Target phase) - событие достигает целевого элемента
  3. Фаза всплытия (Bubbling phase) - событие поднимается от цели к корневому элементу

event.preventDefault() отменяет действие по умолчанию (например, переход по ссылке).

Делегирование Событий

Делегирование событий - это техника, которая использует всплытие событий для обработки событий на родительском элементе вместо установки обработчиков на каждый дочерний элемент. 

// Вместо установки обработчиков на каждую кнопку
document.getElementById('buttonContainer').addEventListener('click', function(event) {
    if (event.target.tagName === 'BUTTON') {
        alert('Кнопка ' + event.target.textContent + ' была нажата!');
    }
});

События Мыши

События мыши позволяют отслеживать движение курсора и взаимодействие пользователя с мышью.

Основные события мыши:

  • click - возникает при клике мышью (нажатие и отпускание)
  • dblclick - возникает при двойном клике
  • mousedown - возникает при нажатии кнопки мыши
  • mouseup - возникает при отпускании кнопки мыши
  • mousemove - возникает при движении мыши
  • mouseover - возникает при наведении курсора на элемент
  • mouseout - возникает при уходе курсора с элемента
  • mouseenter - возникает при входе курсора в элемент (не всплывает)
  • mouseleave - возникает при выходе курсора из элемента (не всплывает)
  • contextmenu - возникает при вызове контекстного меню (правый клик)
  • wheel - возникает при использовании колеса мыши

Свойства объекта события мыши:

Свойство Описание
clientX, clientY Координаты относительно окна браузера
pageX, pageY Координаты относительно документа
screenX, screenY Координаты относительно экрана
offsetX, offsetY Координаты относительно элемента, на котором произошло событие
button Какая кнопка мыши была нажата (0 - левая, 1 - средняя, 2 - правая)
buttons Битовая маска нажатых кнопок мыши во время события

Подробное описание кода отслеживания координат

Код выше демонстрирует следующие концепции:

  1. Создание элемента-индикатора - мы создаем видимый указатель, который следует за мышью
  2. Получение различных типов координат - мы показываем разные типы координат (client, offset, screen)
  3. Обработка событий входа и выхода - мы используем mouseenter и mouseleave для управления видимостью указателя
// Объяснение основных элементов кода
    // 1. Получаем ссылки на DOM-элементы
    const tracker = document.getElementById('mouseTracker'); // Контейнер для отслеживания
    const pointer = document.getElementById('mousePointer'); // Визуальный указатель
    const output = document.getElementById('mouseOutput');   // Элемент для вывода информации
    
    // 2. Добавляем обработчик события движения мыши
    tracker.addEventListener('mousemove', function(event) {
        // Обновляем позицию указателя, используя offsetX/Y (координаты относительно элемента)
        pointer.style.left = event.offsetX + 'px';
        pointer.style.top = event.offsetY + 'px';
        
        // Выводим различные типы координат:
        // - clientX/Y: координаты относительно видимой области окна браузера
        // - offsetX/Y: координаты относительно элемента, на котором произошло событие
        // - screenX/Y: координаты относительно экрана устройства
        output.innerHTML = `
            clientX/Y: ${event.clientX}, ${event.clientY}
            offsetX/Y: ${event.offsetX}, ${event.offsetY}
            screenX/Y: ${event.screenX}, ${event.screenY}
        `;
    });

Пример: Рисование с использованием координат мыши

Этот пример демонстрирует, как использовать координаты мыши для создания простого инструмента рисования. Удерживайте кнопку мыши и перемещайте её внутри холста, чтобы рисовать.

Координаты указателя появятся здесь
// Код для рисования на холсте
    const canvas = document.getElementById('drawingCanvas');
    const ctx = canvas.getContext('2d');
    const colorPicker = document.getElementById('colorPicker');
    const brushSize = document.getElementById('brushSize');
    const output = document.getElementById('drawingOutput');
    
    // Настройки
    let isDrawing = false;
    let lastX = 0;
    let lastY = 0;
    
    // Обработчики событий мыши
    canvas.addEventListener('mousedown', startDrawing);
    canvas.addEventListener('mousemove', draw);
    canvas.addEventListener('mouseup', stopDrawing);
    canvas.addEventListener('mouseout', stopDrawing);
    
    function startDrawing(e) {
        isDrawing = true;
        [lastX, lastY] = [e.offsetX, e.offsetY];
    }
    
    function draw(e) {
        if (!isDrawing) return;
        
        // Вывод координат
        output.textContent = `Рисование на X: ${e.offsetX}, Y: ${e.offsetY}`;
        
        // Настройка контекста рисования
        ctx.lineWidth = brushSize.value;
        ctx.lineCap = 'round';
        ctx.strokeStyle = colorPicker.value;
        
        // Рисование линии
        ctx.beginPath();
        ctx.moveTo(lastX, lastY);
        ctx.lineTo(e.offsetX, e.offsetY);
        ctx.stroke();
        
        // Обновление координат
        [lastX, lastY] = [e.offsetX, e.offsetY];
    }
    
    function stopDrawing() {
        isDrawing = false;
    }
    
    // Очистка холста
    document.getElementById('clearCanvas').addEventListener('click', function() {
        ctx.clearRect(0, 0, canvas.width, canvas.height);
    });

Drag and Drop (Перетаскивание)

HTML5 предоставляет встроенный API для реализации операций перетаскивания элементов. Этот API позволяет создавать интерактивные интерфейсы с возможностью перемещения элементов.

Основные события Drag and Drop:

  • dragstart - возникает, когда пользователь начинает перетаскивание элемента
  • drag - возникает каждые несколько миллисекунд во время перетаскивания
  • dragenter - возникает, когда перетаскиваемый элемент входит в целевую область
  • dragover - возникает при перетаскивании элемента над целевой областью
  • dragleave - возникает, когда перетаскиваемый элемент покидает целевую область
  • drop - возникает, когда элемент брошен в целевую область
  • dragend - возникает после завершения операции перетаскивания

Как реализовать Drag and Drop:

  1. Добавьте атрибут draggable="true" к элементам, которые нужно перетаскивать.
  2. Добавьте обработчик события dragstart для этих элементов.
  3. Используйте dataTransfer для хранения данных во время перетаскивания.
  4. Добавьте обработчики событий dragover и drop к целевым элементам.

Пример простой реализации Drag and Drop:

// Для перетаскиваемого элемента
element.addEventListener('dragstart', function(event) {
    // Сохраняем ID или другие данные элемента
    event.dataTransfer.setData('text/plain', event.target.id);
    // Можно установить изображение перетаскивания
    event.dataTransfer.setDragImage(image, xOffset, yOffset);
});

// Для зоны сброса (drop zone)
dropZone.addEventListener('dragover', function(event) {
    // Разрешаем сброс на этот элемент
    event.preventDefault();
});

dropZone.addEventListener('drop', function(event) {
    event.preventDefault();
    
    // Получаем ID перетаскиваемого элемента
    const id = event.dataTransfer.getData('text/plain');
    const draggedElement = document.getElementById(id);
    
    // Добавляем элемент в зону сброса
    event.target.appendChild(draggedElement);
});
