Объект Event

При возникновении события создается объект Event, который содержит детали о произошедшем событии и автоматически передается в функцию-обработчик. 

button.addEventListener('click', function(event) {
    console.log(event.type);      // "click"
    console.log(event.target);    // элемент, на котором произошло событие
    console.log(event.clientX);   // X-координата клика (для событий мыши)
    console.log(event.clientY);   // Y-координата клика (для событий мыши)
});

Демонстрация:

Основные свойства объекта Event

Свойство Описание
type Тип события (например, "click", "keydown")
target Элемент, на котором произошло событие
timeStamp Время возникновения события
preventDefault() Метод для отмены действия по умолчанию

Разница между event.target и this

В обработчиках событий важно понимать разницу между event.target и ключевым словом this:

  • event.target - элемент, который инициировал событие (на котором произошло событие)
  • this - элемент, к которому прикреплен обработчик события

Нажмите на любое место в цветных блоках ниже, чтобы увидеть разницу:

Внешний блок
Внутренний блок 
// HTML структура
<div id="container">
    Внешний блок
    <div class="inner">Внутренний блок</div>
</div>

// JavaScript
const container = document.getElementById('container');

container.addEventListener('click', function(event) {
    // event.target - элемент, на котором произошел клик
    console.log('event.target:', event.target.textContent);
    
    // this - элемент, на котором установлен обработчик (container)
    console.log('this:', this.textContent);
    
    // Проверка равенства
    console.log('target === this:', event.target === this);
});

Когда использовать event.target и this?

  • event.target используйте, когда вам нужен конкретный элемент, на котором произошло событие.
  • this используйте, когда вам нужен элемент, на котором зарегистрирован обработчик.

Важно: При использовании стрелочных функций this работает иначе. Стрелочные функции не имеют собственного this, поэтому в них this является ссылкой на внешний контекст:

// Обычная функция - this указывает на элемент
element.addEventListener('click', function(event) {
    console.log(this); // Элемент, к которому прикреплен обработчик
});

// Стрелочная функция - this НЕ указывает на элемент
element.addEventListener('click', (event) => {
    console.log(this); // Window или другой внешний контекст
});

Дополнительные примеры использования this

Рассмотрим различные контексты использования this в обработчиках событий:

Особенности работы this в разных контекстах

  • Обычный обработчик события: this указывает на элемент, к которому прикреплен обработчик.
  • Метод объекта без привязки: При использовании метода объекта как обработчика, this теряет контекст объекта и указывает на элемент.
  • Стрелочная функция: Сохраняет this из внешнего контекста, где была создана.
  • Метод с bind(): this всегда указывает на объект, к которому привязан, независимо от способа вызова.
// Примеры различных контекстов this
const obj = {
    name: 'Мой объект',
    
    // Метод объекта
    regularMethod: function() {
        console.log(this.name); // 'Мой объект' только при прямом вызове
    },
    
    // Стрелочная функция
    arrowMethod: () => {
        console.log(this.name); // undefined или значение из внешнего контекста
    },
    
    // Метод с привязкой контекста
    boundMethod: function() {
        console.log(this.name); // Всегда 'Мой объект' после bind
    }.bind(this)
};

Глубокое погружение в this

1. Контекст this в различных ситуациях

Внутренний блок

Особые случаи работы с this

1. Потеря контекста
const button = {
    name: 'Моя кнопка',
    init: function() {
        // this теряется в callback-функции
        document.addEventListener('click', function() {
            console.log(this.name); // undefined
        });

        // Решение 1: использование bind
        document.addEventListener('click', function() {
            console.log(this.name);
        }.bind(this));

        // Решение 2: стрелочная функция
        document.addEventListener('click', () => {
            console.log(this.name);
        });
    }
};
2. Методы класса и this
class Button {
    constructor(name) {
        this.name = name;
        // Привязка в конструкторе
        this.handleClick = this.handleClick.bind(this);
    }

    // Метод класса
    handleClick() {
        console.log(this.name);
    }

    // Метод с автоматической привязкой (class fields)
    handleHover = () => {
        console.log(this.name);
    }
}
3. this в асинхронном коде
const asyncExample = {
    name: 'Асинхронный объект',
    
    // Потеря контекста в setTimeout
    wrongWay() {
        setTimeout(function() {
            console.log(this.name); // undefined
        }, 1000);
    },
    
    // Правильный способ
    rightWay() {
        setTimeout(() => {
            console.log(this.name); // 'Асинхронный объект'
        }, 1000);
    }
};
Советы по работе с this:
  1. Используйте стрелочные функции для автоматического сохранения контекста
  2. Применяйте bind() для явной привязки контекста
  3. В классах используйте поля класса со стрелочными функциями для методов-обработчиков
  4. Помните, что this в обычных функциях определяется в момент вызова
  5. В обработчиках событий this указывает на элемент, к которому прикреплен обработчик

document.getElementById('preventDefaultLink').addEventListener('click', function(event) {

});
