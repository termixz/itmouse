Методы Обработки Событий

Существует три основных способа добавления обработчиков событий:

1. HTML-атрибуты (не рекомендуется)

<button onclick="alert('Кнопка нажата!')">Нажми меня</button>

Демонстрация:

Не рекомендуется использовать этот метод, так как он смешивает HTML и JavaScript, что затрудняет поддержку кода.

2. Свойства объекта DOM

let button = document.querySelector('button');
button.onclick = function() {
    alert('Кнопка нажата!');
};

Демонстрация:

Важно: Используя свойства объекта DOM, мы можем назначить только один обработчик для каждого типа события на элементе.

3. Метод addEventListener (рекомендуется)

let button = document.querySelector('button');
button.addEventListener('click', function() {
    alert('Кнопка нажата!');
});

// Можно добавить несколько обработчиков
button.addEventListener('click', function() {
    console.log('Еще один обработчик для того же события');
});

Демонстрация:

Удаление обработчиков событий

// Для свойства объекта DOM
element.onclick = null;

// Для addEventListener
function handler() {
    console.log('Обработчик события');
}
element.addEventListener('click', handler);
element.removeEventListener('click', handler);
